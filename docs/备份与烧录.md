# Halo M-Key CC2530 改造资料包（非烧录固件）

## 重要状态
- `HALO_M_KEY_GPIO.h`：已实测的六键映射。
- **不含已编译 ESP32 `.bin` 或 Halo `.hex`**；ESP32 烧录器仍需适配 ESP32_MOS_X4，FreePad 仍需移植和编译。
- Halo LED 未接，第一阶段禁用 LED。

## ESP32_MOS_X4 主机 GPIO 约束

根据用户的 ESPHome 接线配置：

| GPIO | 现有用途 | 烧录器是否可用 |
|---|---|---|
| 16 / D16 | 进水阀 MOS | **禁止** |
| 17 / D17 | 废水/冲洗阀 MOS | **禁止** |
| 18 / 19 | TDS UART TX/RX | 禁止 |
| 21 / 22 | I²C SDA/SCL | 禁止 |
| 23 | 状态灯 | 已占用 |
| 4 / 13 | 流量计 | 已占用 |
| 14 | 蜂鸣器 | 已占用 |
| 25 / 32 | 漏水/高压输入 | 已占用 |
| 26 / 27 | 阀/泵 MOS | 已占用 |

当前不能仅凭 YAML 推断三个可用调试脚。先核对 ESP32_MOS_X4 原理图、排针和实际 PCB；避免占用启动绑带脚、Flash 引脚、USB-UART 或板载外设。此前提出的 GPIO18/19/21 候选已撤销。

## ESPHome OTA 切换

用户当前 ESPHome YAML 使用 `esp32: board: esp32dev`、Arduino framework，OTA 为 `platform: esphome` 且启用加密；未见显式自定义 partition 配置。可行路径是让当前 ESPHome OTA 接收一次匹配经典 ESP32的 app-only 镜像，但尚未核实实际 Flash 容量、编译后的 OTA slot 大小及烧录器程序大小，因此**目前不能保证直接 OTA 成功**。

- 必须编译 classic ESP32（不是 ESP32-S3）固件。
- 使用 app-only OTA image，不可使用含 bootloader/partition table 的 factory image。
- 镜像必须适配当前 OTA 分区布局并小于 inactive OTA app slot。
- 当前 OTA 加密密钥需要用于上传认证。
- 切换后原 ESPHome API/OTA 消失；烧录器固件需另加 OTA 更新功能，或使用 USB-UART 恢复。
- 在切换前备份 ESPHome YAML、secrets、Flash/分区信息，并确认 USB 恢复能力。

官方资料：https://esphome.io/components/ota/esphome/ 和 https://esphome.io/guides/cli/

## CC2530 上位机源码与接线

上游：https://github.com/z9m/ESP32-CC-Tool-Pro

该上游当前默认 `esp32-s3-devkitc-1`，不是本项目 `esp32dev`。上游 README 默认 GPIO4=DC、GPIO5=DD、GPIO6=RESET；经典 ESP32 的 GPIO6 常属于 SPI Flash，禁止照抄。须先改为实际板上确认空闲的 GPIO。

CC2530 端：DC -> P2.2（34脚），DD -> P2.1（35脚），RESET -> RESET_N（20脚），GND 共地。目标电源必须采用单一、受控的 3.3V 方案，先断开纽扣电池；不得接 5V。

## 原厂固件备份

1. 接线和供电确认后启动烧录器，先执行 Detect/Identify。
2. 确认芯片型号、Flash 容量和保护状态。
3. 未读保护时读取 Flash，保存为 `halo_m_key_original_01.bin`。
4. 再读一次保存为 `halo_m_key_original_02.bin`，比较 SHA-256。
5. 保存两份离线备份及工具版本、读回长度、芯片 ID。
6. **双重备份完成前，不执行 Erase / Unlock / Write。** 读保护解除可能导致整片擦除。
7. 不要把原厂固件备份提交到公开仓库。

## FreePad 低功耗移植

上游：https://github.com/diyruz/freepad

S1...S6 分别为 P1.2...P1.7，按下接地，掩码 0xFC。需要在上游真实按键扫描/中断实现中映射六键，验证上拉、P1 中断、PM3 唤醒、Z-Stack 网络恢复和 Z2M 设备识别。仅有 GPIO 头文件不能生成可烧录 HEX；禁止将 LeTV HEX 直接写入 Halo。
