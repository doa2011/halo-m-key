# Halo M-Key CC2530 改造资料包（非烧录固件）

## 重要状态
- `HALO_M_KEY_GPIO.h`：已实测的六键引脚映射，可供移植工程引用。
- **不含已编译 ESP32 `.bin` 或 Halo `.hex`**；尚未在目标 ESP32_MOS_X4 板上核实空闲 GPIO，也未完成 FreePad 源码移植、IAR/Z-Stack 编译及实机验证。
- 未确定 LED 的 GPIO，第一阶段禁用 LED。

## 上位机源码
https://github.com/z9m/ESP32-CC-Tool-Pro

源码 README 默认 ESP32 GPIO4=DC、GPIO5=DD、GPIO6=RESET。**经典 ESP32 GPIO6 往往用于 SPI Flash，禁止在 ESP32-WROOM 板上直接沿用。**

建议候选：GPIO18=DC、GPIO19=DD、GPIO21=RESET，前提是已用该 MOS 板原理图/通断测试确认这三个引脚可用且无负载；并同步修改项目 src/main.cpp 的 HARDWARE CONFIG。不要仅按 ESP32 端丝印给任意 MOS 输出端接线。

接线：ESP32 DC -> CC2530 P2.2(34脚)，DD -> P2.1(35脚)，RESET -> RESET_N(20脚)，GND 共地。目标电源按单一受控 3.3V 方案供电，先断开纽扣电池；确认电压、负载及电源容量。不要外接 5V。

## 备份原厂固件（优先）
1. 先确认目标板接线与供电，烧录 ESP32 上位机固件。
2. 连接热点 ESP32-CC-Flasher（原项目默认密码 12345678），进入 http://192.168.4.1。
3. 执行 Detect / Identify；确认 CC2530、Flash 容量与保护状态。
4. 如果未加读保护，执行 Read/Dump，下载 `halo_m_key_original_01.bin`。
5. 再次读取保存为 `halo_m_key_original_02.bin`，在电脑端用 sha256sum 对比。
6. 将备份文件至少保存两份，记录芯片容量、工具版本和读回结果。
7. **未成功备份前不执行 Erase / Unlock / Write；受读保护时解除锁定可能整片擦除**。

## FreePad 低功耗移植
https://github.com/diyruz/freepad

已证实按键 S1...S6 分别为 P1.2...P1.7，按下接地，合计掩码 0xFC。需要在上游真实按键扫描及中断实现中映射六键，配置稳定上拉，验证 P1 端口中断的唤醒与消抖、Z-Stack PM3 与网络恢复。注意 P1.6/P1.7 的兼容、全部按键是否唤醒，及原固件 Z2M 设备标识/转换器。

源码编译需匹配 IAR 8051 + TI Z-Stack / FreePad 依赖；仅有这份头文件不可编译生成 HEX。禁止将 LeTV 固件直接写入 Halo。
